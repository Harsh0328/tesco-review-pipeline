# Tesco Customer Review Data Pipeline
# Architecture: Hybrid Network Interception

## 1. Executive Summary
Following the rejection of official API access and CSV exports, we have pivoted to a **Hybrid Network Interception** architecture. This approach combines the bot-bypassing capabilities of a real browser with the stability and structured data of an API. 

## 2. The Problem with Traditional Approaches
1. **Direct API Calls (Requests/cURL):** Blocked by Tesco's Akamai Bot Manager (403 Forbidden) because they lack the dynamic cryptographic cookies and browser fingerprints generated by a real browser session.
2. **HTML DOM Scraping (Playwright + BeautifulSoup):** Extremely brittle. Tesco frequently changes CSS classes, div structures, and A/B tests their UI. A scraper relying on HTML selectors requires constant maintenance and breaks often.

## 3. The New Architecture: "Network Interception" (Wiretapping)
Modern single-page applications (SPAs) like Tesco.com load a basic skeleton page and then fetch the actual data (like reviews) in the background via hidden JSON API calls to their backend (`xapi.tesco.com`). 

Instead of trying to parse the messy visual HTML layer, our new pipeline acts as a **network wiretap**:
1. We use Playwright to drive a real browser, naturally generating the required Akamai cookies and passing bot detection.
2. We inject a network listener (`page.on('response')`) directly into the browser's networking stack.
3. As the browser scrolls and Tesco's frontend requests the reviews from its backend, our listener intercepts the clean, structured JSON payload in transit.
4. We extract the exact data points we need directly from the JSON, bypassing the HTML DOM entirely.

### Advantages of this approach:
- **Resilient to UI Changes:** Tesco can completely redesign their website; as long as the underlying data structure remains similar, our pipeline will not break.
- **Bypasses Enterprise Security:** By using a real browser context, Akamai sees a legitimate user session.
- **Clean Data:** We receive structured JSON, avoiding the messy text-cleaning required when scraping HTML.

## 4. Smart Triaging Engine
All intercepted reviews are processed through a custom NLP/Keyword matching engine to instantly flag actionable intelligence:
- **QA Risks (Critical):** Scans for food safety and severe quality indicators (e.g., 'sick', 'plastic', 'blown', 'smell'). 
- **Logistics Issues:** Scans for supply chain and delivery failures (e.g., 'missing', 'late', 'driver', 'substitute').
- **Sorting Logic:** The final output dynamically sorts data so that Critical QA Risks and 1-star reviews are bubbled to the very top for immediate visibility by the management team.
